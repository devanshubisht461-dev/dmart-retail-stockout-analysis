# Retail Stockout Analysis and AI Agent Development

## Project Overview

This project analyses retail store performance and investigates whether inventory stockouts contribute to lower revenue, using a DMart-inspired five-store scenario.

## Objectives

* Generate and inspect retail datasets.
* Identify and correct data-quality issues.
* Engineer analytical features.
* Compare performance across five stores.
* Investigate relationships between revenue, footfall and stockout hours.
* Develop an evidence-based recommendation.

## Tools and Technologies

* Pandas
* SQLite (planned for later development)
